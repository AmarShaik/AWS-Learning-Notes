# AWS Learning Journey

This repository contains my notes, concepts, practical learning, and doubts while learning Amazon Web Services (AWS).

My goal is to understand AWS from the fundamentals to advanced cloud, DevOps, deployment, and infrastructure concepts.

## Learning Goals

- Understand cloud computing fundamentals
- Learn AWS core services
- Understand cloud infrastructure and networking
- Learn deployment and DevOps concepts
- Practice AWS through real-world projects
- Maintain clear and beginner-friendly technical notes

## Learning Approach

For every topic, I will focus on:

1. Understanding the basic definition
2. Learning concepts in simple language
3. Understanding real-world examples
4. Learning why the concept is needed
5. Understanding how it connects with AWS
6. Recording doubts and their easy explanations
7. Practicing the concept wherever possible

## Doubts and Clarifications

During my learning journey, I will record questions and doubts that arise while studying.

After clarifying a doubt, I will add:

- The original question
- The simple explanation
- A real-world example when needed

This will help me revise difficult concepts easily in the future.
